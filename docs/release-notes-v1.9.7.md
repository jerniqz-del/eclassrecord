# E-Class Record v1.9.7

Release date: September 7, 2026

## Transmutation Table Lookup

- Click any transmuted grade on the Grading Sheet, summary, or learner grade views to open the matching official transmutation table.
- The popup highlights the initial-grade range and transmuted grade that apply to that cell.
- Transferred-out, transferred-in, and empty cells do not open the table.
- Initial grades in the popup always use two decimal places, including whole numbers such as 24.00.
- Transmuted grades stay whole numbers. Descriptive letter grades stay A–E.
- Close the popup with Done, the close button, clicking outside, or Escape.

## Desktop Profiles and Reliability

- Manage desktop profiles from the app, including restore from a dedicated profile backup.
- Deleting a desktop profile requires saving a complete backup first. PIN-protected profiles remain encrypted in that backup.
- When Windows locks, the active E-Class Record profile stays locked until the teacher unlocks it.
- If the app becomes unresponsive, Wait, Reload safely, and Exit return to a locked profile-selection state instead of wiping records.
- Settings include local crash diagnostics, a sanitized support-bundle export, and deletion of local diagnostic data. Diagnostics are never uploaded automatically.

## Compatibility

- Existing profiles, grades, attendance, assessments, backups, Advisory records, and formulas remain compatible.
- This update does not change stored raw scores. Transmuted grades continue to be calculated from existing scores and the official tables.
