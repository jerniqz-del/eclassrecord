# Facebook Post - E-Class Record v1.4.6

E-Class Record App v1.4.6 is now available as a public patch update.

This update focuses on attendance correctness and safer score-record handling.

What's fixed:

- SF2 Male/Female Total Per Day now counts present learners, not absences
- Excused and No Classes attendance states now reflect better across roll call, tables, legends, statistics, and SF2
- Clear This Date and Mark All Present now properly clear saved Excused/No Classes states
- Assessment Details now preserves scores, HPS, descriptions, dates, titles, and attachments when saving
- Class Record columns now stay in their proper assessment groups after editing assessment titles
- Grading Sheet score cells now support arrow-key navigation
- Transfer Scores preview and styling were improved
- Attendance Tracker, tour popups, and modal behavior received polish

Existing records, grades, backups, and formulas remain compatible.
