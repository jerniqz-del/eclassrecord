# E-Class Record v1.9.5

Release date: August 14, 2026

## Name Picker and Classroom Tools

- Redesigned Name Picker presentation mode around Wheel of Learners and Carnival Prize Wheel.
- Added picking history, a class star leaderboard, Add Star and Undo Last Star controls, and a functional Reset Term Stars action.
- Added wheel size and selection-speed controls, plus the option to remove or retain a learner after being picked.
- Improved selected-learner placement, two-line name fitting, avatar spacing, presentation panels, and learner visibility.
- Added drag-and-drop movement between randomized groups, group summaries, move history, Undo Move, and Restore Randomized controls.

## Calendar and Performance Checklist

- Replicated the updated School Calendar design with a full month grid, event filters, upcoming events, calendar summaries, local events, and optional DepEd synchronization.
- Improved Performance Checklist presentation and fixed the password prompt used when deleting an activity.
- Removed the obsolete Performance Checklist page banner.

## Grading Experience

- Show the View score history action only for score cells with actual changes.
- Removed the orange highlight previously applied to changed score cells.

## Updates and Compatibility

- Enabled differential Windows update packages and silent update installation so existing users do not need to step through a full reinstall.
- Existing profiles, grades, attendance, assessments, backups, Advisory records, avatars, and Grade Transfer files remain compatible.
