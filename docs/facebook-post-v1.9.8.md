# Facebook Post - E-Class Record v1.9.8

E-Class Record App v1.9.8 is now available as a public update.

This update adds DepEd Order No. 017, s. 2026 Strengthened Senior High School subjects, while Grade 12 in SY 2026-2027 stays on the 2016 catalog unless the class is a pilot SSHS section.

What's new:

- Grade 11 uses the Strengthened SHS curriculum
- Grade 12 in SY 2026-2027 uses the 2016 K to 12 subjects by default
- Pilot schools can mark a Grade 12 class as Strengthened SHS
- Grade 12 from SY 2027-2028 uses Strengthened SHS automatically
- 2016 Grade 12 classes use DepEd Order No. 8, s. 2015 weights with the DO 15 transmutation table
- The 6-digit PIN unlocks automatically after the last digit

Existing records, grades, backups, and formulas remain compatible.
