# Facebook Post - E-Class Record v1.10.1

📢 E-Class Record App v1.10.1 is now available!

This is a small update for teachers using Attendance Tracker.

What's fixed:

- Take Roll Call opens again
- Clicking a date on the monthly calendar opens roll call for that day
- The week date strip in roll call updates when you choose another date

Existing records, grades, attendance marks, backups, and formulas stay compatible.

💻 How to get the update
• New users: https://github.com/jerniqz-del/eclassrecord/releases/download/v1.10.1/E-Class-Record-Setup-1.10.1.exe
• Existing users: open the app → Settings → Check for Updates
