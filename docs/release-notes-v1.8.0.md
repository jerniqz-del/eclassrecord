# E-Class Record v1.8.0

Release date: July 29, 2026

## Learner Avatars

- Automatically assign a stable human avatar to each learner using separate libraries of 50 male and 50 female presets.
- Use a neutral default when learner sex is not specified, or manually choose any bundled avatar from the learner profile.
- Keep avatars consistent across class transfers, Advisory rosters, backups, Shared Folder Sync, and mobile sync while storing no learner photos or biometric data.
- Show compact learner identities in class rosters, grading sheets, Quick Grade, Group Randomizer, Name Picker, Grade Simulator, and Performance Checklist.

## Teacher Tools

- Watch learner avatars move between temporary groups before Group Randomizer settles into its final complete or sex-balanced result.
- Shuffle learner avatars beside names using the same slowing roulette timing in both Name Picker and the Performance Checklist mini picker.
- Celebrate each selected learner with a short, local confetti animation, with all motion disabled when reduced-motion preferences are active.
- Assign every randomized group a distinct, securely shuffled color scheme that remains stable until the next randomization.
- Keep group numbers and names visible alongside color, and retain color markers in printed group lists.

## Recurring Performance Activities

- Create multiple Recitations, Notebook checks, Assignments, or custom activities in the same class term.
- Give every activity its own title, date, Highest Possible Score, scoring mode, note setting, and grade destination.
- See every created activity as a separate table column while using the Active Activity selector for focused filtering, Bulk Mark, and the mini Name Picker.
- Review individual activity values in printed summaries and CSV exports.

## Official Grade Integrity

- Add checklist points to a compatible Written Work or Performance Task score in the same class, term, component, and MAPEH strand.
- Rank unused assessments first, prioritizing empty targets with matching HPS and safely preparing an unused slot when its HPS is not yet configured.
- Warn when a target would cause learner scores to exceed HPS, disable unsafe targets, and block the entire publication instead of partially applying it.
- Preserve existing official scores by adding the checklist contribution and showing every before, contribution, and after value in the review.
- Prevent duplicate publication and require profile PIN verification when protection is enabled.
- Lock every published activity against score, note, Bulk Mark, mini-picker, HPS, title, date, and destination edits while its points remain in the official grading sheet.
- Allow a PIN-verified Unlock Activity review to restore every affected official score, mark the activity unpublished, preserve its checklist points, and then make the full activity editable again.
- Revert one activity publication, including an automatically prepared empty assessment, without changing other activity publications or later official edits.

## Compatibility

- Existing combined checklist sessions remain available and retain their entries and publication history.
- Recitation, Notebook, and Assignment activities now always use numerical scores, including older check-mark activities, with direct entry and HPS-aware minus/plus controls.
- Activity records remain inside the encrypted profile database and existing backup format.
- Shared Folder Sync continues to merge activity and entry records by stable IDs.
- Randomizer, Name Picker, Grade Simulator, attendance, grading formulas, and official backup integrity remain unchanged.
