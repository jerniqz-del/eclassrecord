# Facebook Post - E-Class Record v1.4.5

E-Class Record App v1.4.5 is ready as a public update.

This update restores and polishes the full v1.4 feature set, including Attendance, the Help Assistant, Dashboard improvements, cleaner learner transfer, and the new global sidebar sponsor system.

What's New:

- Attendance Tracker with SF2 PDF download flow
- Floating Help Assistant with offline FAQ answers and Start Over
- Ask the Community support when online
- Dashboard grid/list view and drag-and-drop class ordering
- Compact class card assessment summaries
- Easy learner transfer across classes for clean beginning-of-year roster correction
- Cleaner Teaching Load and Grading Sheet layouts
- Separate What’s New and Terms & Conditions modals
- Global sidebar sponsor ads managed by the app owner
- Safer build, checkpoint, and release workflow

Existing class records, learner data, scores, grading formulas, backups, and PDFs remain compatible.
