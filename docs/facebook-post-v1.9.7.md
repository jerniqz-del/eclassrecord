# Facebook Post - E-Class Record v1.9.7

E-Class Record App v1.9.7 is now available as a public update.

This update makes transmuted grades easier to check and keeps desktop profiles safer to manage.

What's new:

- Click any transmuted grade on the Grading Sheet to open the official transmutation table
- The matching initial-grade range and transmuted grade are highlighted
- Initial grades in the table always show two decimal places (example: 24.00)
- Transmuted grades stay whole numbers (example: 65)
- Manage desktop profiles in the app, including restore from a profile backup
- Deleting a desktop profile now requires saving a complete backup first
- If Windows locks, your E-Class Record profile stays locked until you unlock it
- If the app stops responding, you can wait, reload safely, or exit without wiping your records

Existing records, grades, backups, and formulas remain compatible.
